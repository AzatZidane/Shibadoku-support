# Политика конфиденциальности Shibadoku

Обновлено: 21 ноября 2026 года. Разработчик: Azat Ismagilov. Политика относится к версиям Shibadoku для iOS и Android.

## Данные приложения

Shibadoku работает без регистрации и подключения к интернету. Приложение не собирает и не передаёт разработчику персональные данные, не использует рекламу, аналитику, сторонние SDK или отслеживание.

Игровой прогресс и настройки хранятся локально на устройстве. Приложение не запрашивает доступ к контактам, геолокации, камере или микрофону.

## Экспорт и импорт

Вы можете самостоятельно экспортировать прогресс в JSON и передать файл выбранному получателю через системные средства. Передача происходит только по вашему действию. Выбранный вами сервис или получатель обрабатывает файл по собственным правилам. Импорт читает только выбранный вами файл сохранения.

## Удаление и резервные копии

В iOS удаление приложения и резервные копии устройства управляются операционной системой и вашими настройками Apple.

В Android игровой прогресс и настройки хранятся в локальных данных приложения. Автоматическое облачное резервное копирование этих данных отключено. Чтобы сохранить или перенести прогресс, самостоятельно экспортируйте JSON. Очистка данных приложения в настройках Android или удаление приложения удаляет локальный прогресс и настройки.

Экспортированные вами файлы хранятся в выбранном месте; удалить их можно самостоятельно. Удаление приложения не удаляет эти файлы. Если вы сами сохраняете экспорт в облачном сервисе, его обработка и хранение определяются правилами выбранного сервиса. Разработчик не хранит серверную копию прогресса.

## Дети

Приложение не собирает данные пользователей, включая детей. Учётная запись для игры не требуется.

## Поддержка и эта страница

[Связаться с разработчиком](https://github.com/AzatZidane/Shibadoku-support/issues/new). Обращения в GitHub Issues публичны. Не отправляйте личные данные в текст обращения.

Эта страница размещена на GitHub. Когда вы посещаете GitHub или создаёте обращение, действует [политика конфиденциальности GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). Это отдельный сайт; приложение не отправляет ему данные автоматически.

## Изменения

При изменении обработки данных эта политика будет обновлена с указанием даты.

# Shibadoku Privacy Policy

Last updated: November 21, 2026. Developer: Azat Ismagilov. This policy covers the iOS and Android versions of Shibadoku.

Shibadoku works offline without registration. The app does not collect or transmit personal data to the developer. It contains no advertising, analytics, third-party SDKs, or tracking. It does not request access to contacts, location, camera, or microphone.

Game progress and preferences remain on your device. You may explicitly export a JSON save file and share it through a service or recipient you choose. That recipient's own policies apply. Import reads only the save file you select.

On iOS, device backups and app deletion are controlled by your operating system and Apple settings.

On Android, game progress and preferences are stored in local app data. Automatic cloud backup of this data is disabled. Manually export JSON to keep or transfer progress. Clearing app data in Android Settings or uninstalling the app removes local progress and preferences.

Exported files remain in the location you choose and can be deleted separately; uninstalling the app does not delete them. If you choose to save an export to a cloud service, that service's policies govern its processing and storage. The developer does not keep a server copy of progress. The app does not collect data from children or other users.

For support, [open a GitHub issue](https://github.com/AzatZidane/Shibadoku-support/issues/new). Issues are public; do not include sensitive information. Visits to GitHub and support requests are governed by [GitHub's privacy policy](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). The app does not automatically transmit data to GitHub.

This policy will be updated, with a revised date, if data practices change.
